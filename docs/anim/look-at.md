# 看向（Look-at）：程序化脊椎旋转

`crab_feast/src/anim/look.rs`

按住 Ctrl 转镜头（只转镜头、不改行进方向）时，上半身拧向镜头的朝向；镜头
俯视时角色跟着低头。不是剪辑混合 —— `LookLeft` / `LookRight` 只能覆盖两个方向，斜上方、斜下方这些
组合只能靠两段剪辑交叉淡入，中间态的份额不受控制。这里的做法是**在动画姿态之上**
叠加一个纯偏航 + 俯仰的旋转，逐根骨骼分配。

## 骨骼链与份额

只驱动这五根（Mixamo 命名，其他 rig 按名字匹配 `Chest` / `UpperChest` 兜底）：

偏航和俯仰**各有一张份额表**：轴向旋转（拧）和屈伸（仰头/低头）在人体里是两套
完全不同的能力——腰椎几乎不能拧却能弯，颈椎反过来。一张表走两个轴会让抬头
把整条腰掰弯。

| 骨骼 | 中文 | 偏航份额 | 俯仰份额 | 偏航上限 | 抬头上限 | 低头上限 |
|---|---|---|---|---|---|---|
| `Spine` | 腰椎 | 0.10 | 0.05 | 10° | 5° | 8° |
| `Spine1` | 下胸椎 | 0.16 | 0.07 | 20° | 6° | 9° |
| `Spine2` | 上胸椎 | 0.24 | 0.10 | 30° | 8° | 11° |
| `Neck` | 颈椎 | 0.32 | 0.42 | 38° | 24° | 28° |
| `Head` | 头骨 / 寰枕 | 0.18 | 0.36 | 26° | 18° | 22° |

- **拧**：脊柱组 0.50 / 颈椎组 0.50。65° 的侧看落到每根是
  6.5° / 10.4° / 15.6° / 20.8° / 11.7°——胸口相对髋转了 **32°**，整条背都参与，
  不是只有脖子的假人扭头；腰只给 6.5°（L1–L5 本来合计就只能拧 5° 左右）。
  到 120°（镜头绕到正后方）时是 10 / 20 / 30 / 38 / 22——胸椎合计 **60°**、
  颈椎 60°，正好把配置上限用完，不会出现「头停在 90°」的静态截断。
  这五根 caps 合计 124° ≥ 120°，代码里还有一层保险：实际输入上限取
  `min(yaw_left, Σ caps)`，以后改 caps 也不会再被悄悄截断。
- **仰俯**：脊柱组 0.22 / 颈椎组 0.78。抬头 40° 时腰只有 2°、下胸 2.8°、上胸 4°，
  其余 31° 在颈段；不会出现「一抬头整个人往后折」。

默认整体限幅：偏航 ±120°、抬头 40°、低头 35°。120° 是站着拧腰的解剖上限
（胸椎 40~50° + 颈椎 60~70°）；真正 180° 回头看真人得挪脚转身，拧腰做不到。

分配算法不是简单按份额切一刀：先按份额分，每根夹到自己的上限，被夹掉的部分
再按剩余份额二次分配，直到分完或全部到顶。所以单根骨骼永远不会被拧成橡皮。

## 两个维度 + 方向限幅

- 偏航：绕模型 `+Y`，正 = 向左；左右可以给不同上限（`yaw_left` / `yaw_right`）。
- 俯仰：绕模型 `+X`，正 = 抬头；`pitch_up` / `pitch_down` 分开配置。
- 软饱和：进入上限前最后 30%（`soft_zone`）开始用 smoothstep 压扁，到上限处
  斜率为 0，再大就硬夹。输入可以随便大，观感上只是「越转越吃力」，不会撞墙。
- 总输入还有角速度上限（`max_speed`，默认 220°/s），镜头甩得再快头也不瞬移。

### 大角度回头：顺带低头

纯偏航看起来像风扇转头——真人的颈椎扭转是斜轴，角度一大视线会自然落到肩后
偏低处。所以加了 `yaw_dip_start`（默认 50°）/ `yaw_dip_per_deg`（默认 0.18）：

```text
dip = −max(0, |偏航| − 50°) × 0.18      // 度数，负 = 低头
65°  → 2.7° 低头（几乎看不出，正常侧看不被干扰）
120° → 12.6° 低头（视线明显往下落到肩后）
```

关键实现细节：这个低头**不能**并进俯仰通道再按份额分配。俯仰是绕 X、偏航是
绕 Y，把俯仰塞在链中间，前面几节压下去的量会被后面几节的偏航转成横向
（实测 120° 时只剩 1/3）。正确做法是：偏航分配照旧，低头单独结算，最后在
**头骨的局部轴**上右乘一次 `RotX(-dip)`。头骨是链上最后一节，右乘等于「头自己
低头」，不管头已经偏航多少度，方向都是真往下。

## 头颈先行

真实的人瞟一眼只动脖子，持续盯着看才把胸椎带过来。实现成两条时间常数不同的通道：

```text
脊柱目标 = 总输入 × 组份额比        （spine_secs = 0.45s，慢；拧 0.50、仰俯 0.22）
颈椎目标 = 总输入 − 脊柱当前角度     （cervical_secs = 0.10s，快）
```

两通道之和恒等于总输入，所以头会立刻到位，身体在后面慢慢跟上；等身体转过来，
脖子再退回自己那份。快速一瞥（< 0.2s）基本只有头颈在动，长看才会把整条背带起来
（拧到 65° 时躯干最终会承担 32°）。

## 旋转数学

每根骨骼拿到的是模型空间里的 `R = Ry(yaw) · Rx(-pitch)`，再换算到父骨骼空间，
**左乘**到当前动画姿态上：

```text
q_local_new = (P⁻¹ · R · P) · q_local_anim
```

`P` 是父骨骼**当前**的世界旋转，沿链逐根累加得到（已经包含动画和本层刚写进去的
旋转）。这样即使动画本身把脊柱弯着，偏航也是绕当下这根脊椎的轴转，而不是绕世界
Y 轴硬拧 —— 后者在弯腰时会变成侧倾。累加出的 `P` 里也包含 `Armature`、`Hips`
这些不驱动的节点，Mixamo 的 Z-up 转换不会丢。

坐标约定（与 `input::yaw_of` 一致）：模型正前 `+Z`、上 `+Y`、角色左 `+X`。

## 接入

插件已经随 `AnimPlugin` 注册；本地角色的模型根会自动挂上 `LookAt` + `LookState`。

```rust
// 每帧写角度（相对角色正前方，度）
commands.entity(model_root).insert(LookAt::new(30.0, 12.0));

// 或看向世界里的一个点（眼睛位置通常取头骨）
look.yaw = LookAt::toward_point(eye, point, facing.yaw).yaw;
```

资源上关掉相机驱动、自己控制：

```rust
settings.drive_from_camera = false;
```

联机远端角色：模型根不是 `AnimModelRoot`，需要自己插 `LookAt` 和 `LookState`
（骨骼绑定会在第一帧自动完成）。把服务器同步来的偏航/俯仰写进 `LookAt` 即可。

## 按住 Ctrl：只转镜头，不改行进方向

平时两者是**联动**的：镜头绕多少，摇杆的「屏幕深处」就转多少，身体跟着转向。
看向层平时**完全不驱动**（权重 0）—— 转镜头只是观察，上半身照旧跟着动画走。

**只有按住 Ctrl 才驱动看向**，这时才把三件事拆开：

| | 相机（`LookController`） | 移动 / 朝向 | 上半身 |
|---|---|---|---|
| 默认 | 自由绕 | 跟着相机转 | 不驱动（`weight = 0`） |
| 按住 Ctrl | 只绕 ±160°（到上限停住） | **冻在按下那一刻**（`OrbitLock`） | **看向镜头朝向**（视线的水平方向） |

实现要点：

- `input::orbit_lock_system` 在 `ControlSet::Camera` 里紧跟 `CameraSet::Place`，
  上升沿把**本帧**的 `CameraFacing.yaw` 存进 `OrbitLock`，松开当帧清掉。
- 「屏幕深处」只有一份换算 `input::movement_view_forward(&camera, lock)`：
  本地 `movement_system`、预测端 `predict::pred_velocity`、上行 `net::send_input`
  三处都读它。少冻一处，三端各跑一条方向，和解会一直往回拽。
  冻的是**基向量**（不是输入）：按住 Ctrl 时推摇杆照样换方向，只是「上」还是
  「按下那一刻的上」。
- 看向侧 `drive_look_from_camera` 读同一个锁：按住时按**镜头朝向**（不是机位
  位置）算角度——偏航 = 视线水平朝向 − 角色朝向，俯仰 = −机位仰角。镜头绕到
  侧面、角色还在直线走时，头跟着镜头的指向转过去；120° 上限照旧生效，所以
  镜头转到角色正前 / 正后时会停在 120°（胸口拧 60°、脖子再补 60°），不会拧成橡皮。
  不按住时只把 `LookAt::weight` 置 0（`blend_secs` 淡出），**角度留着不动**——
  淡出期间脖子不会突然甩回 0°。
- 松开那一帧基准换回当前相机，角色按 `TURN_SPEED` 把朝向追过来（不瞬移）。

### 按住时的轨道限位

按住 Ctrl 时镜头不再 360° 无死角：轨道角被夹在「按下基准 ± **160°**」以内
（`input::ORBIT_HOLD_YAW_LIMIT_DEG`），到边界直接停住。比上半身能看的 120°
多留 40° 余量——镜头还能再往外推一点，让玩家看清「头已经到底了」。

夹取放在 **`look_system` 积分那一刻**（`clamp(基准−160°, 基准+160°)`），
不是等一帧再纠正：`CameraSet::Place` 是按累计角摆机位的，如果先越界一帧再夹，
玩家就会看到「先冲过去、再被拽回来」的橡皮筋。现在是一到边界原地不动，
反向拖动立刻从边界往回走（不攒欠账、没有回弹）。`orbit_lock_system` 里每帧
再核一次的夹取只是兜底，防止别的代码绕过输入直写累计角。

- 界内拖动照常跟随；越过 160° 停住；松开 Ctrl 立刻恢复自由绕（限位不跟着走）。
- 基准取镜头自己的 `LookController::accumulated_yaw`，而不是 `CameraFacing`：
  后者是上一帧摆完机位才公布的，同一帧里鼠标增量已经加进累计角，用它会差一个
  拖动量，按下瞬间会「回弹」一下。
- 注意是**相对按下基准**而不是相对角色朝向：按下那一刻镜头若已经在 180°，
  上限就从 180° 起算 ±160°，不会把镜头硬拽回角色正面。
- 看向上限仍是 120°：镜头转到 120~160° 之间时，上半身已经到解剖极限，
  继续转镜头只是换个观察角度，角色不会跟着再拧。

对应测试：`input::tests::orbit_lock_*`（边沿锁存 + 世界方向不随镜头转）、
`anim::look::tests::camera_drive_engages_only_while_orbit_lock_is_held`
（不按 Ctrl 权重 0、按住才写角度）、`..._camera_angles_use_the_view_direction_...`
（+90° 侧绕 → 看向量 +90、俯仰取 −机位仰角）。

## 调参建议

- 觉得「头转得不够」：先确认 `Σ yaw_cap` 够不够（当前 124°），再抬 `yaw_left/right`
  与 Spine1/Spine2 的 caps；只抬 Neck/Head 会让大角度全靠脖子，看着假。
- 觉得「躯干跟得太快、像整体转身」：加大 `spine_secs`（0.6~0.9）。
- 觉得「一瞥时头也在慢慢转、没有先到位」：减小 `cervical_secs`（0.06~0.08）。
- 觉得「转到边上突然停」：降低 `soft_zone`（0.5），把软区拉长。
- 动作幅度大的剪辑（跳跃、翻滚）里想减少干扰：给该角色 `LookAt::weight = 0`，
  会平滑淡出，不是硬切。

## 边界

- 没有眼球骨骼：视线方向由头骨承担，眼睛不会先于头转。
- 没有锁骨 / 肩胛：大幅侧看时肩膀不跟着抬起。需要的话在 `LOOK_BONES` 之外
  再加一层会破坏「脊椎链」的语义，建议另开一个肩部层。
- 超过 120° 的「回头看」不会自动转身体：真人到这一步是挪脚转身，那是角色朝向层
  （`facing_system`）的职责，这一层只负责上半身能看多远。
